# Centelha AL, Fase 2: guia da proposta

Página de apoio para preparar a Fase 2 (Projeto de Fomento) do Programa Centelha 3 Alagoas, com base no Edital FAPEAL nº 06/2026 (2ª retificação, 23/10/2026).

Material independente, sem vínculo com a FAPEAL ou com o Programa Centelha. Em caso de divergência, vale o edital.

## O que tem

- Início com contagem regressiva, progresso, próximo passo e resumo do programa
- Plano de trabalho, datas oficiais, documentos, formulário, informações a levantar, orçamento e organização
- Biblioteca de modelos com pré-visualização (declarações, cartas e planilhas)
- Marcações salvas no navegador, com exportação e importação em arquivo

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicação

Cada push na branch `main` gera o build e publica no GitHub Pages pelo workflow em `.github/workflows/deploy.yml`.
